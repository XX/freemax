# Доменная модель

## Глоссарий

- **Участник** (`Participant`) — человек или организация/сообщество.
- **Круг** (`Circle`) — множество участников, удовлетворяющих условиям вхождения круга.
- **Членство** (`Membership`) — связь участник ↔ круг с ролью и статусом.
- **Объявление** (`Listing`) — потребность (`need`) или предложение (`offer`) предмета, ресурса или услуги.
- **Отклик** (`Response`) — готовность участника удовлетворить потребность или принять предложение.

## Сущности

```
Participant 1─* Membership *─1 Circle
Participant 1─* Listing *─* Circle   (через listing_circles)
Listing     1─* Response *─1 Participant
```

Схема БД: [`migrations/0001_init.sql`](../migrations/0001_init.sql). Типы: [`crates/core`](../crates/core/src).

## Роли в круге

| Роль | Права |
|------|-------|
| `owner` | всё, включая правила круга и удаление |
| `admin` | заявки, исключение, модерация объявлений |
| `member` | публикация, просмотр, отклики |

## Правила вступления (`circles.rules`, JSONB)

```json
{ "join": "open" | "approval" | "invite", "conditions": [] }
```

- `open` — вступление сразу (`active`).
- `approval` — заявка (`pending`), решение админа.
- `invite` — только по приглашению.
- `conditions` — зарезервировано под автоматические условия (не MVP).

## Инварианты

1. Объявление опубликовано минимум в одном круге, где автор — активный участник.
2. Видеть объявление и откликаться может только активный участник хотя бы одного из его кругов.
3. Нельзя откликнуться на собственное объявление.
4. У круга ровно один `owner`.
