# Каркас интерфейса

Этап 0. Зависимости: 03.

## Сделать

- Общий layout страницы на wingy-hypertext (`layouts::page`): шапка, навигация, основная область.
- Раздача статики (`tower-http` `ServeDir`): Web Awesome, htmx, стили из `wingy-hypertext/webassets`.
- Частичный рендер для htmx-запросов (`HX-Request` → только фрагмент).
- Страницы ошибок 404/403/500 в общем layout.

## Готово, когда

- `/` рендерится в layout со стилями Web Awesome, переход по навигации работает через htmx без полной перезагрузки.
