# Протокол обмена

## Жизненный цикл

**Объявление:** `active` → `reserved` (принят отклик) → `closed` (передано) | `archived` (снято/истекло).
Из `reserved` можно вернуться в `active`, если отклик отменён.

**Отклик:** `proposed` → `accepted` | `declined`; `accepted` → `completed` | `cancelled`.

```
участник B видит объявление A (общий круг)
B → отклик (proposed)
A → accepted          ⇒ объявление reserved, контакты раскрыты обеим сторонам
A или B → completed   ⇒ объявление closed
```

## Правила

- Эквивалентность и взаимность не требуются и не учитываются.
- Объявление «предложение» может принять несколько откликов, если автор так решит (например, ресурс делится).
- Отменить можно на любом этапе до `completed`.
- Выход автора из круга снимает объявление из этого круга; если кругов не осталось — `archived`.

## HTTP (MVP, HTML + htmx)

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/` | Лента по всем кругам участника |
| GET/POST | `/circles` | Список / создание кругов |
| GET | `/circles/{id}` | Круг и его лента |
| POST | `/circles/{id}/join` | Вступить / подать заявку |
| POST | `/circles/{id}/members/{pid}` | Решение по заявке, смена роли |
| GET/POST | `/listings` | Форма / публикация объявления |
| GET | `/listings/{id}` | Объявление и отклики |
| POST | `/listings/{id}/responses` | Откликнуться |
| POST | `/listings/{id}/responses/{pid}` | Сменить статус отклика |

JSON API для внешних клиентов и федерации — после MVP.
