# Требования

## Цель

Дать людям и сообществам простой способ отдавать и получать безвозмездно внутри доверенных кругов.

## Принципы

- **Безвозмездность** — нет цен, баланса, валюты, обязательной взаимности.
- **Круг — граница доверия** — объявление видно и доступно для отклика только участникам кругов, где оно опубликовано.
- **Самоуправление кругов** — правила вступления задаёт создатель/администрация круга.
- **Минимум личных данных** — контакты раскрываются только участникам сделки.

## Функциональные требования (MVP)

| ID | Требование |
|----|------------|
| F1 | Регистрация и вход участника (человек или организация). |
| F2 | Создание круга: название, описание, правила вступления. |
| F3 | Вступление в круг согласно правилам; выход из круга. |
| F4 | Администрирование круга: одобрение/отклонение заявок, назначение админов, исключение. |
| F5 | Публикация объявления (потребность / предложение) в одном или нескольких своих кругах. |
| F6 | Лента объявлений по кругам с фильтром: тип, категория, статус, поиск по тексту. |
| F7 | Отклик на объявление; принятие/отклонение отклика автором. |
| F8 | Закрытие объявления после передачи; отметка «выполнено». |
| F9 | Сообщения между автором и откликнувшимся в рамках отклика. |
| F10 | Уведомления о новых откликах и заявках (в приложении, позже e-mail). |

## Позже (не MVP)

- Автоматические условия вступления (домен e-mail, членство в другом круге, геозона).
- Вложенные круги и федерация между инстансами (открытый протокол).
- Автоподбор: сопоставление потребностей и предложений.
- Фото к объявлениям, геопоиск.
- Репутация/отзывы (без влияния на право получать).

## Нефункциональные требования

- Серверный рендеринг HTML (wingy-hypertext + htmx), работа без SPA.
- Мобильная вёрстка.
- PostgreSQL — единственное хранилище; миграции в репозитории.
- Проверка прав доступа к кругу на каждом запросе на чтение/запись объявлений.
- Локализация: русский (по умолчанию), английский.
